# Beta comments

Anonymous, numbered feedback from free-code beta testers (`RSF-BETA-01`, `RSF-BETA-02`, `COVENANT-AI`, `LISTINGPRO`, `AGENTOS-X`).

## For Grok / engineering

1. Read each `####-module.md` file.
2. Use **Page title**, **Page path**, and **Module** to find the UI.
3. Implement the **Suggestion**.
4. Check off the implementation checklist in the file when done.

## File naming

```
0001-outreach.md
0002-command-center.md
session-s_xxxxx.md   ← session index (still anonymous)
```

Comments never include the tester’s name or email — only a random session id.
